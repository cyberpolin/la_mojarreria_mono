# TAKU Site

Public product onboarding website for `taku.lat`.

It explains the two sellable TAKU MVPs and sends users to the product-specific
web UIs:

- TAKU WA: `https://wa.taku.lat`
- TAKU Bot: `https://bot.taku.lat`

## Local development

```bash
pnpm --filter @taku/site dev
```

Default local URL: `http://localhost:3006`.
